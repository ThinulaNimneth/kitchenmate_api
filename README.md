app : https://kitchenmate-web.vercel.app

## Technologies
 
- Node.js,TypeScript
- MongoDB with Mongoose 
- JWT access and refresh tokens  
- Google Gemini API (AI recipes) 
- Hosting: Render(backend), Vercel(front end)

## Features 
- Register and login with JWT 
- Role-based authorization (admin,user) 
- Pantry items 
- Categories 
- Analytics dashboard 
- AI recipe generation  about to expire 
- Admin user management
